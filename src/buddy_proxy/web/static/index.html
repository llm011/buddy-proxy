模型顺序 同一模型的候选上游按序尝试，未输出任何内容就失败时自动换下一档

从上往下按序尝试，某个渠道失败就换下一个，并给失败渠道打 5 分钟冷却标记 （反复失败延长至 1 小时），期间请求自动跳过它。
仅当尚未向客户端输出任何内容就失败时才会换档——已开始流式返回后不再重试 （防止上游重复计费）。因此 codebuddy 通道的流式错误不会换档 （上游把错误放在流里，代理无法感知），把它排在末位更实用。
模型名可下拉选择或手输（上游实际接受的 id 可能与目录名不同）；拖拽 ⠿ 或按 ▲▼ 调整顺序。清空全部目标 = 恢复历史路由（按模型 id 自动匹配）。
注意：客户端把 model 写成 通道/模型 时是明确指定通道， 会直接走该通道、不参与这里的换档；想要自动换档请让客户端只传模型名。
